# salary-app

Учёт зарплаты чаттера: Telegram-бот + Mini App с календарём, статистикой и выплатами.
Данные хранятся только на компьютере, где запущен бот (SQLite). В репозитории — только код.

## Что умеет
- **Календарь месяца**: заработок по дням, бонусные смены, концы периодов выплат.
- **Главная**: прогресс цели на месяц, прогноз, текущие периоды, сколько должен овнер.
- **Статистика**: месяцы, дни месяца, дни недели, рекорды, таблица по месяцам.
- **Выплаты**: что ещё не выплачено и сколько дней ждёшь, история, средняя задержка, отчёт для сверки с овнером.
- **Настройки**: ставки с датой начала действия (старые смены не пересчитываются), доп. начисления (бонусы и штрафы),
  названия моделей, цели, пересчёт в гривны по курсу НБУ.
- **Бот**: быстрый ввод смены кнопками, уведомления о закрытых периодах и задержках выплат, Excel-выгрузка,
  ежедневный бэкап базы.

## Как устроено
```
Telegram ──► Mini App (GitHub Pages, папка docs/)
                │  https + подпись Telegram initData
                ▼
        туннель Cloudflare (trycloudflare.com, бесплатно)
                ▼
   bot.py на ПК: aiogram-бот + API (aiohttp) + SQLite
```
Каждый запрос к API проверяется подписью Telegram и списком `ALLOWED_USERS`,
поэтому без своего аккаунта Telegram к данным не попасть, даже зная адрес.

## Установка (Windows)
1. Python 3.10+ с галочкой «Add Python to PATH».
2. Скопируй `.env.example` в `.env` и заполни: токен бота от @BotFather, свой Telegram ID, адрес GitHub Pages.
3. Запусти `start_bot.bat`. Он сам поставит зависимости и скачает `cloudflared.exe`.
4. Остановить — `stop_bot.bat`.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `docs`.

## Ставки по умолчанию
Модель 1: обычные 20%, сабки 25%, бандлы 30%; смена от $300 → обычные +5%. Периоды 1–10, 11–20, 21–конец месяца.
Модель 2: 30% от продаж. Периоды 24–08 и 09–23.
Всё меняется в приложении (Ещё → Ставки).
